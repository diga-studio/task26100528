# risktrend — 部门风险趋势统计库

单部门钓鱼识别能力分的内存统计库，由上层报表直接调用。支持任意顺序补录/覆盖历史测评，
查询任意历史时间区间内**按持续时间加权**的部门平均能力分，以及部门处于高风险
（能力分严格低于 50）的累计秒数。

## 业务规则

- 统计范围固定为统计起点后的 365 天，期间员工名单与权重固定不变。
- 员工权重为 1..100 的整数，能力分为 0..100 的整数，时间精确到整数 UTC 秒。
- 任意时刻员工的有效分 = 该时刻之前或恰好该时刻生效的最新测评分；无测评时沿用起点分。
- 同一员工、同一生效时间的再次写入覆盖原分数；补录旧成绩只影响其生效时间到该员工
  下一条测评之间的状态。
- 部门能力分 = 全员有效分按固定权重的加权平均；严格低于 50 为高风险，恰好 50 不计入。
- 查询区间为左闭右开 `[from, to)`，自动裁剪到统计范围；所有变化从生效秒开始计算，
  不按天抽样、不对分数取整。
- 每次写入返回后，后续查询（包括已查询过的历史区间）立即反映更新。

## 使用

```go
import "risktrend"

start := int64(1704067200) // 统计起点，UTC 秒
emps := []risktrend.Employee{
    {ID: "alice", Weight: 3, Initial: 60},
    {ID: "bob",   Weight: 1, Initial: 40},
}
history := []risktrend.Assessment{
    {EmployeeID: "bob", Time: start + 10*86400, Score: 85},
}

s, err := risktrend.New(start, emps, history) // 可同时载入已有测评（任意顺序）
if err != nil { /* 参数非法：权重/分数越界、员工重复、时间出界等 */ }

// 补录或覆盖一条测评（同员工同时间再次写入即覆盖）
err = s.AddAssessment(risktrend.Assessment{EmployeeID: "alice", Time: start + 5*86400, Score: 45})

// 查询 [from, to)：时长加权平均分 + 高风险累计秒数
avg, riskSeconds := s.Query(start, start+90*86400)
```

约束：仅支持单线程顺序调用，不提供并发安全与进程恢复；测评生效时间须在
`[start, start+365天)` 内，否则 `AddAssessment` 返回错误。

## 实现概要

- 部门加权总分 `V(t)`（整数）分段恒定。一次写入只改变某员工在
  `[生效时间, 该员工下一条测评)` 内的有效分，等价于对 `V` 做区间加常数，
  即在该区间两个端点各施加一次差分事件。
- 差分事件序列按时间分块（约 1024 事件/块）维护：块内保存前缀和与
  “按取值排序的前缀时长”，整块查询 O(log 块长)，写入重建单块 O(块长 log 块长)。
- 员工记录用 treap 按生效时间索引，写入/查找期望 O(log n)，不依赖记录分布。
- 平均分 = `V` 的区间积分 / (总权重 × 区间秒数)，积分全程整数运算，误差远低于 1e-6；
  高风险判定用整数比较 `V < 50 × 总权重`，秒数精确。

## 测试

```sh
go test ./...
```

覆盖：非均匀权重与同秒变分、恰好 50 的边界、补录/覆盖与重复写入、稀疏+密集混合的
全年规模场景（500 员工 / 100 万测评 / 1 万查询 + 2000 写入交错，限时 15 秒、
内存 256 MiB），以及 200 组随机差分用例（每次查询都与从全部记录独立重算的结果比对）。
